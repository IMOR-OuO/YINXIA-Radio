# YINXIA Radio · 音乐盒

一个简单、原生的 Android 音频打击垫应用。

</div>

## 简介

把常用音效放进可编辑的 Pad 网格，通过触摸或实体键盘快速播放。应用完全使用 Android 原生能力开发，音频保存在本地，核心功能可离线使用。

## 功能

- 创建、编辑、复制和删除音乐盒
- `2 × X`、`3 × X`、`5 × X` 和自适应 Pad 布局
- 多音轨播放、防止重音、一键停止
- 音频试听、开始/结束位置、音量和速度调整
- 实体键盘与蓝牙键盘快捷键
- 自定义背景、透明度和背景恢复
- `.soundbox` 导入与导出
- 支持 MP3、WAV、OGG、M4A、FLAC、AAC、OPUS

## 构建

需要 JDK 17 和 Android SDK 36。

```powershell
.\gradlew.bat assembleDebug
```

生成的 APK：

```text
app/build/outputs/apk/debug/app-debug.apk
```

## 兼容性

Android 8.0 及以上，支持手机横竖屏、平板、实体键盘和蓝牙键盘。
